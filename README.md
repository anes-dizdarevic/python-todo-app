# python-todo-app
A simple Todo List application built with Python for tracking daily tasks.

## Features
- Add tasks to a list
- View tasks
- Delete tasks
- User-friendly Graphical User Interface (GUI)

## Technologies
- Python
- Tkinter
- GitHub

## Requirements
- Python 3

## How to run
- Ensure python is installed and works
- Download this repository
- Open the project folder and run the file by double clicking or run the command in the terminal of the project's folder:
 ```bash
 python main.py
